## Recommended: get the complete code in one step (GitHub)

Hand-copying 130 files is slow and error-prone. The reliable way to pull the
**entire** buildable project:

1. Open the project in the Lovable editor → top-right **GitHub → Connect to GitHub**
   → authorize. Lovable pushes the whole repo.
2. Locally:
   ```bash
   git clone https://github.com/<you>/<repo>.git onam-site
   cd onam-site
   npm install       # or: bun install
   npm run dev       # http://localhost:3000
   npm run build     # production build to host
   ```

That gives you exactly what's running in the preview, with nothing missing.

## Regenerate the shadcn/ui components (if you keep hand-copying)

The 57 files under `src/components/ui/` are unmodified shadcn "new-york"
components. After `npm install`, regenerate them with:

```bash
npx shadcn@latest add accordion alert alert-dialog aspect-ratio avatar badge \
  breadcrumb button calendar card carousel chart checkbox collapsible command \
  context-menu dialog drawer dropdown-menu form hover-card input input-otp label \
  menubar navigation-menu pagination popover progress radio-group resizable \
  scroll-area select separator sheet sidebar skeleton slider sonner switch table \
  tabs textarea toggle toggle-group tooltip
```

## Hosting notes

- Stack is **TanStack Start** (SSR-capable). `npm run build` outputs a server
  bundle (nitro). Deploy to Node/Vercel/Netlify, or containerize for your AWS
  (behind your existing ALB).
- Fonts load from Google Fonts (Inter, Plus Jakarta Sans, JetBrains Mono).
- Drop your real assets into `public/`: `logo.svg`, `screenshots/*.png`,
  `video/{demo,demo-onboarding,demo-attack-path}.mp4`. `DemoVideos.tsx` has
  commented `videoSrc` slots to switch each clip from animation to the real MP4.
- **Log in** already points to
  `http://a3e22be456af44b03b31800c6a49ae89-349bf801ed209557.elb.ap-south-1.amazonaws.com/ui/`
  — put HTTPS in front of that endpoint.
