Q1: How many clouds get *first-class* treatment?

Everyone says "multi-cloud." Ask each vendor to demo OCI, Alibaba Cloud, or IBM Cloud — not AWS. That's where "multi-cloud" claims go to die.

Q2: Is it one graph, or silos side by side?

A real attack path crosses boundaries: a leaked GCP service-account key that assumes a role into AWS prod is invisible to any tool analysing each cloud separately.

Q3: How does it prioritise?

4,000 "critical" findings = no prioritisation at all. We rank by FAIR-model dollar exposure, so the top of the queue is defensible in business terms — not CVSS arithmetic.

**5/**
Q4: Agentless, and how fast to first finding?

Deployment friction predicts coverage. Onam: read-only role, <3 min to connect, <5 min to first critical alert, no long-lived credentials stored. Ever.
